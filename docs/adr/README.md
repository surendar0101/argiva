# Architecture Decision Records

Each file records one decision: the context, the options considered, the decision and its consequences. File names follow `NNNN-title.md`. The running summary is in [docs/decisions.md](../decisions.md).

To change a decision, write a new ADR that supersedes the old one, and set the old one's status to `Superseded by NNNN`. Do not rewrite history.

## Template

```markdown
# NNNN. Title

- Status: Proposed | Accepted | Superseded by NNNN
- Date: YYYY-MM-DD
- Deciders: Owner (+ agent)

## Context
## Options considered
## Decision
## Consequences
```
